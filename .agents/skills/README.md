# Project-Packaged Skills

This project includes reusable skills that are packaged with the repository.

## Included
- `graph-learning-coach`
- `hierarchical-glossary-maintainer`

## Purpose
These packaged skills are meant to be used with the project-local learner state and glossary conventions:

```text
{project_root}/learning/{student}/
{project_root}/docs/glossary.md
```

This makes the project portable: the learning workflow, lesson plan, glossary maintenance, and coaching skill ship together.
