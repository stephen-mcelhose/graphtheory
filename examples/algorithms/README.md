# Algorithm Examples

This directory contains focused examples for named graph algorithms.

## Included
- `hierholzer.go` — Eulerian circuit construction for undirected and directed graphs
- `kruskal.go` — minimum spanning tree by sorted edge additions
- `prim.go` — minimum spanning tree by tree growth
- `hamiltonian.go` — Hamiltonian backtracking, subset-DP, and exact search examples
