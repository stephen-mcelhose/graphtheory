# Usage Notes

## Example coverage

### Connectivity and centers
- build a path graph
- compute connected components
- compute tree centers

### Matrix-Tree theorem
- build `K4`
- count spanning trees
- expected result: $16$

### Bipartite matching
- build a bipartite graph with left/right partitions
- compute a maximum matching
- expected matching size: $3$

### Max flow
- build a small capacitated network
- compute a max flow from source to sink
- expected max flow value: $5$

### de Bruijn graph and Eulerian circuit
- generate the binary order-3 de Bruijn digraph
- compute an Eulerian circuit
- interpret the circuit as a cyclic sequence construction
