# Start Here

This project is a graph theory learning aid and Go library based on Darij Grinberg's *An introduction to graph theory*.

## Best re-entry points

### If you want to resume learning
1. Read `learning/default_student/resume_here.md`
2. Check `learning/default_student/learner_state.md`
3. Use `docs/lesson_plan.md` and `docs/learning_path.md`

### If you want Laplacian practice specifically
Go to:
- `docs/exercises/laplacian_practice_sheet.md`

Recommended order:
1. Problems 1–3
2. Problems 4–6
3. Problems 7–10
4. Revisit `docs/lessons/matrix_tree.md`

### If you want chapter summaries
Go to:
- `docs/chapters/README.md`

### If you want named graph examples
Go to:
- `docs/named_graphs/README.md`
- `examples/named_graphs/README.md`

### If you want the learner coaching workflow
Go to:
- `.agents/skills/graph-learning-coach/README.md`
- `learning/default_student/`
