# Learning Path for `graphtheory`

This repository can be studied as a progressive graph theory course inspired by arXiv:2308.04512.

## Stage 1. Foundations
1. finite sets, subsets, and counting language
2. simple graphs
3. degrees and adjacency
4. graph families: empty, complete, path, cycle

## Stage 2. Traversal language
5. walks, paths, trails, cycles
6. connectedness and components
7. distances, eccentricity, centers
8. bridges and structural vulnerability

## Stage 3. Special families
9. trees and forests
10. bipartite graphs
11. tournaments
12. hypercubes
13. de Bruijn digraphs

## Stage 4. Classical constructive algorithms
14. BFS and DFS
15. spanning trees and spanning forests
16. Eulerian conditions and circuit construction
17. strong and weak components in digraphs

## Stage 5. Optimization
18. bipartite matching
19. max flow
20. cut reasoning and Menger-style viewpoints

## Stage 6. Algebraic graph theory
21. adjacency matrices
22. Laplacians
23. Matrix-Tree theorem
24. rooted spanning arborescences

## Stage 7. Harder structural topics
25. Hamiltonian paths and cycles
26. chromatic polynomial
27. theory helpers and extremal checks

## Recommended study flow inside this repo
- Start with `docs/named_graphs/`
- Then read `docs/lessons/`
- Then use `examples/named_graphs/`
- Then attempt `docs/exercises/`
- Finally, explore `examples/projects/`
