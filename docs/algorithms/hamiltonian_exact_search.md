# Hamiltonian Exact Search

## Purpose
Exact search explores the full solution space until it finds a Hamiltonian path or cycle or proves none exists.

## Problem family
This is a **vertex-traversal** exponential-time method.

## In this project
- Code: `theory/hamiltonian.go` (`HamiltonianCycleExactSearch`)
- Example: `examples/algorithms/hamiltonian.go`

## Notes
This family includes backtracking, branch-and-bound variants, and subset dynamic programming.
