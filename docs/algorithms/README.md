- `hamiltonian_dp_subsets.md` — subset dynamic programming for small Hamiltonian instances
- `hamiltonian_exact_search.md` — general exact exponential search framing
- `hamiltonian_plan.md` — roadmap for Hamiltonian search methods in the repo
