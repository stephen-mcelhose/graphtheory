# Chapter 7 Summary: Independent Sets

## Core topics
- definition of independent sets
- Caro–Wei theorem
- simpler lower bounds
- proof of Turán's theorem
- introduction to digraph kernels

## Main ideas
- Independent sets are the dual side of coloring: color classes are independent sets.
- Exact maximum independent set search is hard, but useful lower bounds exist.
- Extremal graph theory connects density constraints to sparse substructures.

## Why this chapter matters
This chapter bridges combinatorial optimization, extremal graph theory, and coloring.

## Learning connection
It is partly reflected in theory helpers and gap-analysis notes, but remains more conceptual than fully implemented.
