# Sources

## Primary source

Darij Grinberg, *An introduction to graph theory*, [arXiv:2308.04512](https://arxiv.org/abs/2308.04512). Current version on arXiv is v3 (8 Jun 2025). Grinberg also keeps a more frequently updated PDF at <https://www.cip.ifi.lmu.de/~grinberg/t/22s/graphs.pdf>.

License: [CC0 1.0 Universal](http://creativecommons.org/publicdomain/zero/1.0/). The notes are in the public domain. Summaries, exercises, and implementations in this repo may follow them without a copyright barrier from the paper itself.

That does not make this repo correct. Treat the notes as the spine, then check algorithms and edge cases against other graph theory and algorithms sources when you implement or repair something.
