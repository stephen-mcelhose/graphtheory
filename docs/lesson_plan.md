# Lesson Plan

## Week 1: Foundations
- read `docs/learning_path.md`
- study `docs/lessons/simple_graphs.md`
- read named graph write-ups for empty, complete, path, and cycle graphs
- run named-graph examples

## Week 2: Traversal and structure
- study connectedness, paths, cycles, and bridges
- compare path and cycle behavior
- complete beginner exercises

## Week 3: Trees and bipartite structure
- study trees, centers, and bipartite graphs
- run complete bipartite examples
- complete intermediate exercises on matching and centers

## Week 4: Eulerian graphs and directed structure
- study `docs/lessons/eulerian_graphs.md`
- explore de Bruijn digraph and tournament examples
- compare Eulerian vs Hamiltonian ideas

## Week 5: Flows and matching
- study `docs/lessons/flows.md`
- connect bipartite matching to flow ideas
- do flow and matching exercises

## Week 6: Algebraic graph theory
- study `docs/lessons/matrix_tree.md`
- compare spanning-tree counts across graph families
- do counting mini-projects

## Week 7: Advanced review
- revisit `docs/research_to_implementation_gap.md`
- attempt advanced exercises
- use learner coaching skill for targeted remediation and quizzes
