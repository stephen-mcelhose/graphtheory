# Exercise Hints

## Beginner
- For an empty graph, no vertex has neighbors.
- A path graph has exactly $n-1$ edges.

## Intermediate
- Centers minimize eccentricity.
- In $K_{m,n}$, matching size is at most $\min(m,n)$.
- A graph is bipartite iff it has no odd cycle.

## Advanced
- Tournaments orient complete graphs.
- Eulerian structure is edge-based; Hamiltonian structure is vertex-based.
- The chromatic polynomial is easiest on small graphs.
