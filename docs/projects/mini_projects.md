# Mini Projects

## 1. Named Graph Explorer
Create several named graphs and compare which are connected, bipartite, Eulerian, or Hamiltonian.

## 2. BFS vs DFS
Generate a graph and compare traversal order and the structure exposed by each method.

## 3. Matching and Flow Bridge
Construct a bipartite graph, solve a matching problem, then explain the flow reduction viewpoint.

## 4. Counting Trees
Compare spanning-tree counts across complete, cycle, path, and hypercube examples.

## 5. de Bruijn Sequence Builder
Construct a de Bruijn digraph and interpret an Eulerian circuit as a cyclic sequence.
