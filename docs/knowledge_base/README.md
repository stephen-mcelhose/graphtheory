# Graph Theory Knowledge Base

This knowledge base reorganizes the ingested material from *An introduction to graph theory* (arXiv:2308.04512) into linked concepts for study and retrieval.

## Purpose
- split the paper into reusable linked concepts
- support the learning skill with concept-level retrieval
- connect chapter summaries, lessons, examples, and exercises
- make dependencies between topics explicit

## How to use
1. Start with `index.md`.
2. Follow `groups/` for major concept clusters.
3. Open `concepts/` for specific ideas.
4. Use `crosswalk.md` to connect paper chapters to concept files.
5. Use `study_routes.md` for suggested learning paths.

## Structure
- `index.md` — master topic map
- `crosswalk.md` — chapter-to-concept mapping
- `study_routes.md` — suggested reading sequences
- `groups/` — major thematic clusters
- `concepts/` — linked concept entries

## Source basis
Primary source:
- Darij Grinberg, *An introduction to graph theory*
- arXiv: https://arxiv.org/abs/2308.04512
