# Hamiltonian Backtracking

## Definition
Hamiltonian backtracking is an exact search method that builds a path or cycle one vertex at a time and backtracks when a partial choice cannot be extended.

- Code: `theory/hamiltonian.go`
- Example: `examples/algorithms/hamiltonian.go`
