# Eulerian Path

## Definition
An Eulerian path is a trail that uses every edge of a graph exactly once. Some sources also use the term Euler trail.

## Why it matters
Eulerian paths are one of the clearest examples of a global traversal problem that can be characterized by local degree conditions.

## Classification
- traversal type: edge-traversal problem
- constructive status: constructively solvable in the Eulerian case
