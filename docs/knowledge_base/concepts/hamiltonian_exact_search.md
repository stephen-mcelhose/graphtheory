# Hamiltonian Exact Search

## Definition
A family of exponential-time methods that explicitly search for a Hamiltonian path or cycle and can certify nonexistence by exhaustive exploration.

- Code: `theory/hamiltonian.go`
- Example: `examples/algorithms/hamiltonian.go`
