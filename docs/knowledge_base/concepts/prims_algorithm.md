# Prim's Algorithm

## Definition
Prim's algorithm is a greedy algorithm for constructing a **minimum spanning tree** of a weighted connected graph.

## Intuition
Grow one tree outward by repeatedly adding the cheapest edge connecting the current tree to a new vertex.
