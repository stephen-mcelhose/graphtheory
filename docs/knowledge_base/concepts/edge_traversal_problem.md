# Edge-Traversal Problem

## Definition
An edge-traversal problem is a graph problem whose objective is defined in terms of traversing, covering, or ordering edges, rather than visiting each vertex once.

## Why it matters
This classification helps distinguish Eulerian-type problems from Hamiltonian-type problems:
- Eulerian problems ask to use every edge exactly once.
- Hamiltonian problems ask to visit every vertex exactly once.

## Examples
- Eulerian path
- Eulerian circuit
- route-inspection style questions

- contrasts with: [Hamiltonian Path and Cycle](hamiltonian_path_and_cycle.md)
- differs from vertex-traversal problems by making edge coverage primary
